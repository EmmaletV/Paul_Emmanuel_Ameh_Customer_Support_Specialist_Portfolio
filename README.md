# Paul Emmanuel Ameh — Customer Support Portfolio

A responsive, single-page professional portfolio focused on Customer Service Representative, Customer Support Specialist, customer engagement, CRM documentation, lead follow-up, and service coordination roles.

## Contents

- `index.html` — the complete portfolio website. Styling and JavaScript are embedded in this file, so no build step or package installation is required.
- `assets/Paul-Ameh-CV-Public.pdf` — public-safe CV linked from the portfolio's Download CV buttons. The residential address is replaced with city-level location.
- `assets/customer-request-tracker.xlsx` — fictional sample tracker linked from the portfolio project section.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Confirm the CV and sample tracker downloads work.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `paul-ameh-customer-support-portfolio`.
2. Upload `index.html`, `README.md`, and the complete `assets` folder to the repository's root.
3. Open **Settings → Pages**.
4. Under the build and deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to finish deployment. The public URL will be shown in the Pages settings.

## Before publishing

- Review every employment date, credential name, and achievement against your CV.
- Confirm that your CV is the version you want to share publicly.
- Add your verified LinkedIn URL if you want it displayed on the website. Do not publish unverified profile links.
- Consider replacing the initials avatar with a professional headshot, if desired.
- Open the website on both a phone and desktop and test all navigation and download buttons.

## Accuracy and privacy

The portfolio includes sample case studies, illustrative metrics, and fictional customer records for demonstration purposes. They are not represented as actual employer performance results. The sample tracker contains no real customer information. Do not upload confidential employer data, private customer records, passwords, or API keys.

## Technology

HTML5, embedded CSS, and embedded JavaScript. No package installation or backend is required for the core portfolio.
